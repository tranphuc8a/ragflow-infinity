# Lấy API key RAGFlow

API key là cần thiết để máy chủ RAGFlow xác thực các yêu cầu HTTP/Python hoặc MCP của bạn. Tài liệu này cung cấp hướng dẫn để lấy API key RAGFlow.

1. Nhấn vào avatar của bạn ở góc trên bên phải giao diện RAGFlow để truy cập trang cấu hình.
2. Nhấn **API** để chuyển sang trang **API**.
3. Lấy API key RAGFlow:

![ragflow_api_key](https://raw.githubusercontent.com/infiniflow/ragflow-docs/main/images/ragflow_api_key.jpg)

:::tip LƯU Ý
Xem [Tham chiếu HTTP API RAGFlow](../references/http_api_reference.md) hoặc [Tham chiếu Python API RAGFlow](../references/python_api_reference.md) để có tham chiếu đầy đủ về các API HTTP hoặc Python của RAGFlow.
:::
