# Nhúng Agent vào trang web

Bạn có thể dùng iframe để nhúng một Agent vào trang web bên thứ ba.

1. Trước khi tiến hành, bạn phải [lấy API key](../models/llm_api_key_setup.md); nếu không, thông báo lỗi sẽ xuất hiện.
2. Trên trang **Agent**, nhấp vào Agent mong muốn để truy cập trang chỉnh sửa của nó.
3. Nhấp **Quản lý > Nhúng vào trang web** ở góc trên bên phải của canvas để hiển thị cửa sổ **iframe**.
4. Sao chép iframe và nhúng vào trang web của bạn.
