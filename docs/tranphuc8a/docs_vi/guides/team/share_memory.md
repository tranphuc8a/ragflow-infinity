# Chia sẻ bộ nhớ

Chia sẻ bộ nhớ với các thành viên trong nhóm.

---

Để chia sẻ bộ nhớ với nhóm của bạn:

1. Truy cập trang **Cấu hình bộ nhớ** của bộ nhớ bạn muốn chia sẻ.
2. Đặt **Quyền** thành **Nhóm**.
