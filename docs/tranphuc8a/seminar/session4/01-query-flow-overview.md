# 01 - Query Flow end-to-end trong RAGFlow

## 1. Bức tranh tổng

Luồng chính trong `api/db/services/dialog_service.py::async_chat`:
- Nhận message và config.
- Resolve model bundle (embedding/chat/rerank).
- Tinh chỉnh query (multi-turn, cross-language, keyword expansion, metadata filter).
- Retrieval và rerank.
- Build prompt với `knowledge`.
- Sinh câu trả lời và gắn citation/reference.

## 2. Ý nghĩa kiến trúc

- Query pipeline là nơi hội tụ toàn bộ chất lượng ingest trước đó.
- Đây cũng là điểm cân bằng giữa chất lượng, độ trễ và chi phí token.
