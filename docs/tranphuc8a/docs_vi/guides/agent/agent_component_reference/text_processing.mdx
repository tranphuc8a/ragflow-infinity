# Thành phần xử lý văn bản

Một thành phần gộp hoặc tách văn bản.

---

Thành phần **Text processing** dùng để gộp hoặc tách văn bản.

## Cấu hình

### Method

- Split: Tách văn bản
- Merge: Gộp văn bản

### Split_ref

Chỉ xuất hiện khi chọn **Split**.

Biến cần tách. Gõ `/` để chèn biến nhanh.

### Script

Mẫu để gộp, chỉ xuất hiện khi chọn **Merge**. Gõ `/` để chèn biến nhanh.

### Delimiters

Dấu phân tách dùng để tách hoặc gộp văn bản.

### Output

Tên biến toàn cục cho đầu ra của thành phần, có thể được tham chiếu bởi thành phần khác trong workflow.
