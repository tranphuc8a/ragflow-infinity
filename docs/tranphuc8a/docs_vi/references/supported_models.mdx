:::danger QUAN TRỌNG
Nếu mô hình của bạn không được liệt kê ở đây nhưng có các API tương thích với OpenAI, hãy nhấp vào **OpenAI-API-Compatible** trên trang **Model providers** để cấu hình mô hình của bạn.
:::

## Ví dụ: AI Badgr (tương thích OpenAI)

Bạn có thể sử dụng **AI Badgr** với RAGFlow thông qua nhà cung cấp OpenAI-API-Compatible hiện có.

Để cấu hình AI Badgr:

- **Provider**: `OpenAI-API-Compatible`
- **Base URL**: `https://aibadgr.com/api/v1`
- **API Key**: API key AI Badgr của bạn (từ bảng điều khiển AI Badgr)
- **Model**: bất kỳ ID mô hình chat hoặc embedding nào của AI Badgr, được cung cấp thông qua các API tương thích OpenAI của AI Badgr

AI Badgr triển khai các endpoint tương thích OpenAI cho `/v1/chat/completions`, `/v1/embeddings`, và `/v1/models`, vì vậy không cần thay đổi code bổ sung trong RAGFlow.

:::note
Danh sách các mô hình được hỗ trợ được trích xuất từ [nguồn này](https://github.com/infiniflow/ragflow/blob/main/rag/llm/__init__.py) và có thể không phải là danh sách hiện tại nhất. Để biết danh sách mô hình được hỗ trợ mới nhất, vui lòng tham khảo tệp Python.
:::
