# Chia sẻ Agent

Chia sẻ Agent với các thành viên trong nhóm.

---

:::tip LƯU Ý
Chia sẻ Agent với thành viên nhóm chỉ có sẵn trong phiên bản Enterprise của RAGFlow.
:::

Để chia sẻ Agent với nhóm của bạn:

1. Truy cập trang chỉnh sửa của Agent bạn muốn chia sẻ.
2. Nhấp **Quản lý** ở góc trên bên phải của canvas.
3. Thay đổi **Quyền** từ **Chỉ mình tôi** thành **Nhóm** trong cài đặt Agent.
