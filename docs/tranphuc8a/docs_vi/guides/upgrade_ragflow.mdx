# Nâng cấp
import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

Nâng cấp RAGFlow lên `nightly` hoặc phiên bản mới nhất đã được xuất bản.

:::info LƯU Ý
Việc nâng cấp RAGFlow trong bản thân nó sẽ *không* xóa dữ liệu đã tải lên/lịch sử của bạn. Tuy nhiên, hãy lưu ý rằng `docker compose -f docker/docker-compose.yml down -v` sẽ xóa Docker container volumes, dẫn đến mất dữ liệu.
:::

## Nâng cấp RAGFlow lên `nightly`, Docker image được kiểm tra gần đây nhất

`nightly` đề cập đến RAGFlow Docker image không có mô hình nhúng.

Để nâng cấp RAGFlow, bạn phải nâng cấp **cả** code **lẫn** Docker image của mình:

1. Dừng máy chủ

   ```bash
   docker compose -f docker/docker-compose.yml down
   ```

2. Cập nhật code cục bộ

   ```bash
   git pull
   ```

3. Cập nhật **ragflow/docker/.env**:

   ```bash
   RAGFLOW_IMAGE=infiniflow/ragflow:nightly
   ```

4. Cập nhật RAGFlow image và khởi động lại RAGFlow:

   ```bash
   docker compose -f docker/docker-compose.yml pull
   docker compose -f docker/docker-compose.yml up -d
   ```

## Nâng cấp RAGFlow lên phiên bản cụ thể

Để nâng cấp RAGFlow, bạn phải nâng cấp **cả** code **lẫn** Docker image của mình:

1. Dừng máy chủ

   ```bash
   docker compose -f docker/docker-compose.yml down
   ```

2. Cập nhật code cục bộ

   ```bash
   git pull
   ```

3. Chuyển sang phiên bản đã xuất bản chính thức mới nhất, ví dụ: `v0.23.1`:

   ```bash
   git checkout -f v0.23.1
   ```

4. Cập nhật **ragflow/docker/.env**:

   ```bash
   RAGFLOW_IMAGE=infiniflow/ragflow:v0.23.1
   ```

5. Cập nhật RAGFlow image và khởi động lại RAGFlow:

   ```bash
   docker compose -f docker/docker-compose.yml pull
   docker compose -f docker/docker-compose.yml up -d
   ```

## Câu hỏi thường gặp

### Tôi có cần sao lưu tập dữ liệu trước khi nâng cấp RAGFlow không?

Không, bạn không cần. Việc nâng cấp RAGFlow trong bản thân nó sẽ *không* xóa dữ liệu đã tải lên hoặc cài đặt tập dữ liệu của bạn. Tuy nhiên, hãy lưu ý rằng `docker compose -f docker/docker-compose.yml down -v` sẽ xóa Docker container volumes, dẫn đến mất dữ liệu.

### Nâng cấp RAGFlow trong môi trường ngoại tuyến (không có truy cập Internet)

1. Từ môi trường có truy cập Internet, kéo Docker image cần thiết.
2. Lưu Docker image vào tệp **.tar**.
   ```bash
   docker save -o ragflow.v0.23.1.tar infiniflow/ragflow:v0.23.1
   ```
3. Sao chép tệp **.tar** sang máy chủ mục tiêu.
4. Tải tệp **.tar** vào Docker:
   ```bash
   docker load -i ragflow.v0.23.1.tar
   ```
